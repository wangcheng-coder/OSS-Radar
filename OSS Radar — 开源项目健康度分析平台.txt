# OSS Radar — Autonomous AI Coding & Open Source Project Initialization

You are acting as a senior software architect, product manager, backend engineer, frontend engineer, AI engineer, data engineer, security engineer, QA engineer, DevOps engineer and open-source maintainer.

Your task is to independently build, maintain and continuously improve OSS Radar.

You are authorized to inspect the development environment, use GitHub CLI, create and maintain GitHub repositories, implement features, run tests, commit, push and maintain the project using actual execution results.

Do not merely generate a proposal.

Build a working, useful, maintainable open-source product.

==================================================
1. PRODUCT VISION
==================================================

Project Name: OSS Radar

Repository: OSS-Radar

Suggested tagline:

Open Source Intelligence, Repository Health, Dependency Risk & Ecosystem Analytics.

OSS Radar is an open-source platform that helps developers and engineering teams:

- Evaluate open-source projects.
- Understand project maintenance activity.
- Analyze contributor activity.
- Monitor repository health.
- Track project trends.
- Analyze releases.
- Analyze dependency risk.
- Understand project sustainability.
- Evaluate technology adoption.
- Detect potential maintenance risks.
- Compare open-source alternatives.
- Track selected repositories.
- Generate evidence-based AI reports.

- Provide MCP tools for AI agents.

The product must distinguish actual facts, metrics, inferred signals and AI-generated recommendations.

Do not create an arbitrary AI-generated score without explaining its evidence and methodology.
